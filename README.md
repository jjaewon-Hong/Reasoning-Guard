# Reasoning Guard 
딥러닝 기반 미확인 공중 표적 정밀 판별 시스템


![Reasoning Guard Logo](./assets/Logo.png)


* **Author:** 22212026 홍재원
* **Course:** OSS설계 

## 🛡️ Project Overview
현대 전장의 하이브리드 공중 위협에 대응하여 핵심 표적(미사일·전투기·드론)의 정밀 탐지와 비위협 객체 학습으로 오발사를 원천 차단하고, 하이브리드 엔진(PyTorch/C++) 기반의 3단계 전술 의사결정(SAFE, CAUTION, DANGER)을 단호하게 지원하는 고신뢰성 Fail-safe 소프트웨어입니다.
